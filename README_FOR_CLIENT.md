## 💡 Common Tasks

### Change Home Page Headline
1. Go to `/admin/content`
2. Click **"home"**
3. Find "hero" → "title"
4. Type new headline
5. Click **"Save Changes"**
6. Refresh homepage

### Update Business Hours
1. Go to `/admin/content`
2. Click **"contact"**
3. Find "hours" section
4. Edit "weekday" or "weekend"
5. Click **"Save Changes"**
6. Refresh contact page

### Add New FAQ
1. Go to `/admin/content`
2. Click **"faq"**
3. Find "items" section
4. Click **"Add Item"** button
5. Type question and answer
6. Click **"Save Changes"**
7. Refresh FAQ page

### Change Product Images
1. Upload image to Media first
2. Copy image URL
3. Go to page you want to update
4. Paste URL in image field
5. Click **"Save Changes"**

## ⚡ Important Tips

### ✅ DO:
- **Save frequently** - Don't lose your work
- **Refresh browser** - To see changes
- **Keep backups** - Of important content
- **Test changes** - View on frontend after saving
- **Use clear text** - Write for your customers

### ❌ DON'T:
- **Don't leave fields empty** - Fill all content
- **Don't use HTML** - System handles formatting
- **Don't forget to save** - Always click Save button
- **Don't delete core sections** - Edit, don't remove

## 🛠️ Troubleshooting

### Problem: Changes Not Showing
**Solution:**
1. Hard refresh (Ctrl + Shift + R)
2. Clear browser cache
3. Check you clicked "Save Changes"

### Problem: Can't Save Changes
**Solution:**
1. Check all required fields are filled
2. Refresh admin page
3. Try logging out and back in

### Problem: Lost My Edits
**Solution:**
- Content is saved in database
- Just reload the page
- Your last save is preserved
